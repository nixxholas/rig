# Master plans

A master plan is a short, human-dictated description of how we get from where we
are to where we want to be: the big picture, the ordered steps, and the criteria
that decide whether a step is done. It is the product's intent, not a task list
and not a design document.

These files are written by the user. Agents must read every master plan before
starting work, and must not create, edit, rename, or delete a file in this
directory unless the user explicitly asks for that change in the current task.

When implementation reality contradicts a master plan, say so and ask. Do not
quietly adjust the plan to match the code.
